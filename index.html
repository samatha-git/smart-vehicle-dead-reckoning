Smart Vehicle Dead Reckoning Simulator

Estimate a vehicle’s position when GPS is unavailable, visualize position drift, and compare it with occasional GPS correction.

Simulation controls

0° = north, 90° = east, 180° = south, 270° = west.

Try this: turn GPS correction off, increase sensor error, then run the simulation. The estimated path will drift from the reference path. Turn correction on to see the estimate reset toward the reference.

You can also click anywhere on the map to choose a new starting position.
